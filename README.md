### 🚀 Projects

#### 🛍️ [Abaya Shop](https://github.com/kvltn8/djangonaut): full-stack e-commerce store
An online abaya store with a product catalogue, cart, checkout and an AI shopping assistant.

- **Frontend:** React 18, Vite, React Router, TanStack Query and Tailwind CSS: shop filters and search, product pages, wishlist, cart drawer, account and order pages
- **Backend:** Django REST Framework API with JWT login (Djoser + SimpleJWT) for products, categories, reviews, carts and orders
- **Database:** PostgreSQL with Supabase for storage
- **AI chatbot:** a RAG assistant that searches store documents using embeddings stored in Supabase and answers through an LLM
- **Payments:** M-Pesa checkout flow
- **DevOps:** Dockerized, with a GitHub Actions pipeline that builds the image, runs the pytest suite and health-checks the container; Locust for load testing
- **Security:** secrets kept in environment variables, JWT authentication, CORS and allowed-hosts configuration

🔗 [Live demo](https://) · [Source code](https://github.com/kvltn8/djangonaut)

#### 🌙 [Moodling](https://github.com/kvltn8/MoodlingZkv): mood and task tracker
A mobile and web app for logging your mood, managing daily tasks and getting Quran surah recommendations to match how you feel.

- **Frontend:** React Native with Expo Router and TypeScript, with animations (Lottie, Reanimated), mood gauges and progress rings
- **Backend:** Django REST Framework API with JWT authentication for moods, tasks and surahs
- **Integration:** Quran Foundation API for surah data and reciter audio
- **Database:** PostgreSQL
- **DevOps:** Dockerized backend with a GitHub Actions CI pipeline
